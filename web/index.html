DNS & IP INTELLIGENCE
从域名，找到网络归属。
查询 A / AAAA 地址、反向 DNS（PTR）及 IP 注册组织。
使用服务器系统 DNS；公网 IP 的 Owner 来自对应区域互联网注册机构（RDAP）。
如何理解查询结果
域名可能对应多个 IPv4 / IPv6 地址，结果受 DNS、CDN 和查询位置影响。单次展示最多 32 个地址。
IP → 域名使用 PTR 反向记录，可能为空，不能枚举该 IP 上托管的全部网站。
Owner 表示 IP 注册持有者或分配网络，不一定是网站所有者；国家字段是注册信息，不代表服务器的实际位置。私有 IP 不查询公网注册机构。
